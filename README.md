# ListenTogether

ListenTogether 是一个聚合多平台音源的音乐播放器,并提供基于P2P实现的"一起听"多人同步功能。

## 功能特性

- **多音源聚合**:网易云 / QQ / 酷狗 / 酷我 / B 站 / 咪咕。
- **分享链接解析**:粘贴歌曲、歌单、哔哩哔哩视频/合集链接即可识别。
- **收藏页**:本地收藏歌曲、创建歌单、收藏外部歌单/合集。
- **一起听**:多人同步播放、暂停、切歌、队列、进度。


## 注意事项

- 本项目仅用于个人学习和个人使用场景。
- VIP / 付费内容请遵守各平台的使用条款,本扩展不绕过版权保护。
